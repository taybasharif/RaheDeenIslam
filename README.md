## ۲. بنیادی خصوصیات و شعبہ جات (Core Modules & Features)

1. **لائیو اوقاتِ نماز برائے پاکستان (Live Prayer Timing System):**
   - جامعہ علوم اسلامیہ علامہ بنوری ٹاؤن، کراچی کے فلکیاتی معیار (طریقہ نمبر ۱) کے مطابق ہر شہر کے عین عرض بلد و طول بلد پر مبنی آزادانہ حسابی اوقات۔
   - پاکستان کے ۲۹ اہم ترین شہروں کے درست اوقات (بشمول وہاڑی: `30.0452, 72.3489` اور چشتیاں: `29.7971, 72.8576`)۔
   - سرچ ایبل ڈراپ ڈاؤن مینو: **"اپنا شہر منتخب کریں"**۔
   - منتخب شہر کا نمایاں ڈسپلے: **"آپ کا منتخب کردہ شہر: وہاڑی، پاکستان"** مع براؤزر `localStorage` میں خودکار محفوظیت۔
   - براؤزر جی پی ایس لوکیشن (GPS Geolocation) کی اجازت سے قریبی ترین پاکستانی شہر کی خودکار شناخت۔
   - فعال ریفریش بٹن: **"تازہ اوقات حاصل کریں"** مع اینیمیشن، حقیقی ڈیٹا فیچنگ اور اردو تصدیقی پیغام: *"نماز کے اوقات تازہ کر دیے گئے ہیں۔"*
   - حنفی فقہی مسلک (سایہ دوگنا - مثلین) بطور ڈیفالٹ معیار، مع شافعی/جمہور کے اختیارات۔
   - موسم کی لائیو معلومات بذریعہ Open-Meteo API (درجہ حرارت، موسمی کیفیت اردو میں، نمی، طلوع و غروب)۔

2. **پانچ فرض نمازوں کے خوبصورت کارڈز اور لائیو کاؤنٹ ڈاؤن:**
   - فجر، ظہر، عصر، مغرب، عشاء کے ۵ کارڈز مع موجودہ صورتحال اور تفصیلی گائیڈ لنک۔
   - اگلی آنے والی فرض نماز کے گرد سنہری بارڈر (Golden Highlight)۔
   - بڑا ڈیجیٹل لائیو کاؤنٹ ڈاؤن ٹائمر (ہر سیکنڈ مسلسل اپ ڈیٹ):
     > **اگلی فرض نماز: نمازِ عصر**  
     > `01:25:42`  
     > **نماز شروع ہونے میں باقی وقت**
   - وقت ختم ہونے پر اگلی نماز میں خودکار منتقلی، اور عشاء کے بعد اگلی صبح کی فجر کا کاؤنٹ ڈاؤن۔
   - نصف شب (Midnight) کو خودکار طور پر اگلے دن کے اوقات کا لوڈ ہونا۔

3. **یومیہ تقویمِ عبادات — ۱۱ شرعی اوقات کی تاریخی ترتیب:**
   1. فجر
   2. طلوعِ آفتاب
   3. نمازِ اشراق (طلوعِ آفتاب کے ۱۵ تا ۲۰ منٹ بعد)
   4. نمازِ چاشت (صلاۃ الضحیٰ)
   5. زوال کا وقت (مکروہ وقت جس میں نفل اور سجدہ منع ہے)
   6. نمازِ ظہر
   7. نمازِ عصر (حنفی معیار)
   8. نمازِ مغرب
   9. نمازِ اوابین (مغرب کے بعد کے ۶ سے ۲۰ نوافل)
   10. نمازِ عشاء
   11. نمازِ تہجد (رات کے آخری تہائی حصے کا فلکیاتی حساب)

4. **مکمل نماز گائیڈ اور رکعات (Complete Prayer Guide - Hanafi):**
   - فجر: ۲ سنتِ مؤکدہ + ۲ فرض = ۴ رکعات
   - ظہر: ۴ سنتِ مؤکدہ + ۴ فرض + ۲ سنتِ مؤکدہ + ۲ نفل = ۱۲ رکعات
   - عصر: ۴ سنتِ غیر مؤکدہ + ۴ فرض = ۸ رکعات
   - مغرب: ۳ فرض + ۲ سنتِ مؤکدہ + ۲ نفل = ۷ رکعات
   - عشاء: ۴ سنتِ غیر مؤکدہ + ۴ فرض + ۲ سنتِ مؤکدہ + ۲ نفل + ۳ وتر واجب + ۲ نفل = ۱۷ رکعات
   - جمعۃ المبارک کی مکمل رہنمائی اور خطبہ۔
   - فرض، واجب، سنتِ مؤکدہ، سنتِ غیر مؤکدہ اور نفل کے شرعی درجات کی باوقار تفریق۔
   - نماز کا عملی طریقہ (تکبیر تحریمہ سے لے کر سلام تک) مع مستند عربی اعراب و تسبیحات اور اردو ترجمہ۔

5. **انفرادی نمازوں کے سرشار صفحات:**
   - فجر کی نماز (`#prayer-fajr`)
   - ظہر کی نماز (`#prayer-zuhr`)

## ۵. گٹ ہب اور ورسل پر تعیناتی (GitHub & Vercel Deployment)

### گٹ ہب پر پش کرنے کے مراحل:
```bash
git init
git add .
git commit -m "Initial release of Rah e Deen Islam Islamic Portal"
git branch -M main
git remote add origin https://github.com/<YOUR_USERNAME>/rah-e-deen-islam.git
git push -u origin main
```

### ورسل (Vercel) پر تعیناتی:
1. [Vercel](https://vercel.com) پر لاگ ان کریں اور **Add New Project** پر کلک کریں۔
2. اپنے گٹ ہب اکاؤنٹ سے `rah-e-deen-islam` ریپوزٹری منتخب کریں۔
3. فریم ورک پرسیٹ: **Other** (چونکہ پروجیکٹ میں اسٹیٹک ایچ ٹی ایم ایل + سرور لیس فنکشنز ہیں)۔
4. روٹ ڈائریکٹری: `./`
5. **Deploy** پر کلک کریں۔
6. ورسل چند سیکنڈ میں لائیو پروڈکشن یو آر ایل جاری کر دے گا۔
